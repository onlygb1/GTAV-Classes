# Classes do GTA V

Este repositório contém algumas classes do GTA V que foram conseguidas com engenharia reversa.
# Uso

Para modificar o arquivo do Reclass.NET, você precisa compilar o Reclass a partir do código-fonte; os binários pré-compilados resultarão em erro ao tentar abrir o projeto.
